【故障排查】

如果更新 Gitee Pages 后管理面板保存还是不工作:

1. 确认 Gitee Pages 已更新
   • 访问管理面板
   • 按 F12 打开开发者工具
   • Sources 标签 → assets/AdminView-*.js
   • 搜索 "gitee.com/api/v5"
   • 如果找到，说明是新版本 ✓
   • 如果找到的是 "api.github.com"，说明还是旧版本 ✗

2. 检查 Token 配置
   • 管理面板 → 系统配置
   • 应该显示 "✅ Token 已配置"

3. 查看浏览器错误
   • F12 → Console 标签
   • 尝试保存文章
   • 截图错误信息

4. 运行验证脚本
   • node verify-admin-save.js
   • 如果脚本通过但管理面板不行 → 缓存问题，清除浏览器缓存
